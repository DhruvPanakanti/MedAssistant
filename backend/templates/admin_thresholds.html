Decision Thresholds

Controls the cutoff each condition uses to turn a probability into a "High Risk" / "Low Risk" result.

How this works

Every prediction produces a probability, like 63%. The threshold decides where that number flips from "Low Risk" to "High Risk."

The default is 0.50 — a straight coin-flip cutoff. Anything at or above it is called positive; anything below is called negative.

  • Lower the threshold to catch more true cases — useful when missing a real case matters more than an occasional false alarm.
  • Raise the threshold to only flag "High Risk" when the model is more confident — fewer false alarms, but some true cases may be missed.

The recommended value below isn't a guess — it's calculated from validation data for each condition to balance both sides of that tradeoff. You can use it as-is, or set your own.
